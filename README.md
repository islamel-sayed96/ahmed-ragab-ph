# Ahmed Ragab — Portfolio

موقع بورتفوليو لأحمد رجب، مصوّر فوتوغرافي وصانع أفلام من إسكندرية ومقيم في دبي.
مبني بـ [Astro](https://astro.build) + [GSAP](https://gsap.com)، وبيطلع صفحات HTML جاهزة وسريعة.

> **المحتوى الحالي تجريبي.** الصور مرسومة كإطارات ملوّنة، والأسماء والأرقام والتواصل placeholders لحد ما نستلم درايف أحمد.

- إنجليزي (الأساسي) على `/`، وعربي على `/ar/`
- الوضع الفاتح (ورق) هو الأساسي، ومعاه زرار للوضع الداكن
- الصفحات: الرئيسية · Photography · Films · About

## فكرة التصميم

"بورتفوليو مطبوع": شكل غلاف مجلة وفهرس وصفحات، بخط Serif كبير (Newsreader بالإنجليزي، Amiri بالعربي)، ولونين بيحكوا قصته:
أزرق البحر المتوسط (إسكندرية) وبرتقالي رملي (دبي). أقسام الرئيسية:

1. **الغلاف** — الاسم كبير وصورة غلاف و"في العدد ده".
2. **جملة** — بتنوّر كلمة كلمة مع السكرول، وجواها صور صغيرة.
3. **الفهرس** — أنواع الشغل كفهرس، ومع الماوس بتظهر صورة بتتحرك معاه.
4. **لقطات مختارة** — توزيع غير متماثل زي صفحة مجلة.
5. **الفيديو** — شريط أفقي بيتحرك مع السكرول.
6. **بين بحرين** — إسكندرية ← دبي، وأرقام.
7. **الخدمات** ورأي عميل وشريط العملاء.
8. **احجز** — فورم صغير بيفتح واتساب برسالة جاهزة.

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:4321/
npm run build    # يطلع الموقع الجاهز في dist/
```

## النشر على Hostinger

نفس طريقة موقع مومن: الموقع الجاهز في `dist/`، و`.htaccess` اللي في الروت بيوجّه كل الطلبات له،
وGitHub Actions بيعمل build ويرفع `dist/` الجديد مع كل تعديل في `src/` أو `public/`.

## إضافة المحتوى الحقيقي

| الملف | فيه إيه |
| --- | --- |
| `src/data/site.ts` | الإيميل والتليفون والواتساب والإنستجرام وسنة البداية والعملاء والمعدات |
| `src/data/photos.ts` | الصور: غيّر `demo-…` بـ id الملف من Google Drive، واختار `cat` و`shape` |
| `src/data/films.ts` | الفيديوهات (id من Google Drive) والشوريل |
| `src/i18n/ui.ts` | كل النصوص بالإنجليزي والعربي (النبذة والخبرة والخدمات والـ SEO) |

أي `id` بيبدأ بـ `demo` بيترسم كإطار تجريبي، وأي id تاني بيتحمّل من Drive.
لازم ملفات الدرايف تبقى متشاركة **Anyone with the link**.
