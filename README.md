# Ahmed Ragab — Portfolio

موقع بورتفوليو لأحمد رجب، مصوّر فوتوغرافي وصانع أفلام من إسكندرية ومقيم في دبي.
مبني بـ [Astro](https://astro.build) + [GSAP](https://gsap.com)، وبيطلع صفحات HTML جاهزة وسريعة.

> **المحتوى الحالي تجريبي.** الصور مرسومة كإطارات ملوّنة، والأسماء والأرقام والتواصل placeholders لحد ما نستلم درايف أحمد.

- إنجليزي (الأساسي) على `/`، وعربي على `/ar/`
- تصميم داكن بالكامل
- الصفحات: الرئيسية · Photography · Films · About

## فكرة التصميم

داكن ودافي وسينمائي: أسود وزيتي وبيج، وعناوين Serif كابيتال (Italiana بالإنجليزي وEl Messiri بالعربي)، وتفاصيل صغيرة بخط Mono.
أقسام الرئيسية:

1. **الواجهة** — الاسم كبير، وشريط صور بعرض الشاشة. الصورة النشطة بتكبر وبتملا الخلفية، وبتتقلب لوحدها مع عدّاد (01 / 09).
2. **اكتشف الشغل** — كروت طويلة لكل نوع تصوير بزرار "View"، بعد منحنى.
3. **الشوريل** — فيديو بعرض الشاشة.
4. **عنّي** — صورتين فوق بعض، ونبذة قصيرة، وأرقام.
5. **بعمل إيه** — أيقونات للمهارات (تصوير، فيديو، درون، مونتاج) جنب كولاج صور.
6. **فيديوهات مختارة** و**على المسرح مع** (الفنانين).
7. **رأي عميل** فوق صورة بعرض الشاشة.
8. **الباقات** — صورة، ووصف، و"الباقة فيها إيه"، وقائمة بتتفتح لكل باقة.
9. **اشتغلت مع** (البراندات)، و**يلا نتكلم**: لينكات التواصل والسي في وفورم صغير بيفتح واتساب برسالة جاهزة.

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:4321/
npm run build    # يطلع الموقع الجاهز في dist/
```

## النشر على Hostinger

نفس طريقة موقع مومن: الموقع الجاهز في `dist/`، و`.htaccess` اللي في الروت بيوجّه كل الطلبات له،
وGitHub Actions بيعمل build ويرفع `dist/` الجديد مع كل تعديل في `src/` أو `public/`.

## إضافة المحتوى الحقيقي

| الملف | فيه إيه |
| --- | --- |
| `src/data/site.ts` | الإيميل والتليفون والواتساب والإنستجرام وسنة البداية والعملاء والفنانين والمعدات |
| `src/data/photos.ts` | الصور: غيّر `demo-…` بـ id الملف من Google Drive، واختار `cat` و`shape`. وصور المسرح والصور المنفردة في آخر الملف |
| `src/data/films.ts` | الفيديوهات (id من Google Drive) والشوريل |
| `src/i18n/ui.ts` | كل النصوص بالإنجليزي والعربي (النبذة والخبرة والباقات ورأي العميل والـ SEO) |

أي `id` بيبدأ بـ `demo` بيترسم كإطار تجريبي، وأي id تاني بيتحمّل من Drive.
لازم ملفات الدرايف تبقى متشاركة **Anyone with the link**.
